## 🎯 为什么建这个仓库

作为 Java 开发者，AI 已经不是"未来趋势"，而是**现在进行时**。  
与其被动等待，不如主动拥抱。这个仓库用来：

- 📚 **系统学习** Spring AI、LangChain4j 等 Java 生态 AI 框架
- 🧠 **深度实践** Prompt Engineering、RAG、Agent、Function Calling
- 📝 **每日记录** 学习内容、踩坑经验、代码示例
- 🤝 **开源分享** 如果能帮到同样背景的开发者，再好不过
