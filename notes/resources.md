## 📖 官方文档（优先读）

### Java AI 框架

- [Spring AI 官方文档](https://docs.spring.io/spring-ai/reference/) - Spring 官方出品，Java 开发者首选
- [LangChain4j 官方文档](https://docs.langchain4j.dev/) - Java 版 LangChain，生态丰富
- [Spring AI Alibaba](https://github.com/alibaba/spring-ai-alibaba) - 阿里云适配版，国内友好

### 大模型 API

- [OpenAI API 文档](https://platform.openai.com/docs) - 行业标准，值得精读
- [阿里云百炼](https://help.aliyun.com/zh/model-studio/getting-started/what-is-model-studio) - 国内调用最方便
- [智谱 AI (GLM)](https://open.bigmodel.cn/dev/api) - 中文理解强，免费额度多
- [百度千帆](https://cloud.baidu.com/doc/WENXINWORKSHOP/index.html) - 文心系列

## 🎓 教程与课程

### Prompt Engineering

- [Prompt Engineering Guide](https://www.promptingguide.ai/zh) - 最系统的 Prompt 学习指南
- [OpenAI Prompt Engineering 最佳实践](https://platform.openai.com/docs/guides/prompt-engineering) - 官方出品
- [吴恩达 ChatGPT Prompt Engineering 课程](https://www.deeplearning.ai/short-courses/chatgpt-prompt-engineering-for-developers/) - 免费，2 小时入门

### RAG

- [RAG 实战指南（LangChain 官方）](https://python.langchain.com/docs/use_cases/question_answering/) - 原理通用，主要看流程
- [向量数据库选型指南](https://guangzhengli.com/blog/zh/vector-database/) - 讲的比较清楚
